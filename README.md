# 住宅価格予測システム

国土交通省「不動産情報ライブラリ」の東京都(練馬区・大田区・世田谷区)の実際の不動産取引データ(2025年)をもとに、TensorFlow/Kerasで売買価格を予測するFlaskアプリです。
区・地区名・土地面積・延床面積・築年数・最寄駅までの徒歩分数を入力すると、学習済みモデルが予測価格を表示します。
モデルはGoogle Colabで学習し、保存済みのモデルを読み込んで使用しています(起動時の再学習は不要)。

## 実行方法

    pip install -r requirements.txt
    python app.py

ブラウザで http://127.0.0.1:5000/predict_form を開いてください。
